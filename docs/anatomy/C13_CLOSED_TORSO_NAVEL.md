# C13 — Closed animated torso skin, true recessed navel (27 Oct 2026)

This is a concrete follow-up to C12's limitation: the bare torso used the Blender-authored **clothing shirt's 830 vertices/triangles as if they were skin**. That was a visual approximation with sleeves, clothing topology, and an overlaid umbilical shadow rather than a proper skin depression.

## Actual Godot game work
- Added `scripts/assets/anatomical_torso_surface.gd` creating a **new, separately indexed 2162-vertex / 4320-triangle** continuous torso with anterior, lateral and posterior skin, 45 height rings and 48 points around each ring, plus independently sealed top/bottom caps. It is an entirely *new mesh* built procedurally; **zero triangles** are directly taken from the original shirt. The 830-vertex garment is still sampled only for chest/waist outline and the original 10 Blender body morph target displacements. Torso dimensions are about **53 cm tall** with typical half-width 14–17 cm.
- **True surface deformation for the navel:** subtract an approximately **8.5 mm localized indentation** (Gaussian radius ≈ 18 mm x 19 mm) from the actual torso surface vertices. The contour at y=1.088 m, x=0 measured ≈ **0.06246 m front**, versus ≈ **0.06892 m at x=+3 cm**; this represents an approximately 6.46 mm local recession after surrounding curvature. C12's existing ring, shaded center, paired nipple/areola 3D pieces are retained and now sit on a physically recessed *render mesh*, not merely a dark painted dot. **This is a closed inward dent, not a fully open umbilical canal.**
- Paired shallow chest volume shaping is part of the new continuous 3D torso surface (Gaussian convexity around x±10.5 cm/y1.35m) independently of any gender/sex category. Skin colors derive strictly from public `AppearanceResolver` data. All five original surface/areola/nipple/navel_rim/navel_dark skinned meshes share the existing **17-bone** `character.glb` Skin and ten public body shape morph channels.
- Torso vertex weights smoothly transition from spine (bind 1) to chest (bind 2) along y=1.175..1.355 m; each vertex's weights sum to 1. Morph generation uses the original GLB shirt's front AND back surface as independent nearest shape-change references. Previous `Helper._bake` torso-only anterior reference remains used for areola/nipple/navel details, to avoid mapping them to back panels.
- **Performance correction:** `SimVisual._build_model()` no longer synchronously generates a mesh for every fully clothed resident. Torso mesh construction is **lazy** only when the player selects the validated top outfit `zadne` ("Bez vrchního dílu (anatomie)"); the expensive single generated `ArrayMesh` is cached and reused among all characters. Timed live Godot cold build after this change: default dressed scene ≈2.476s (includes other game meshes), first explicit bare-top switch ≈0.716s additional, second bare actor reuse ≈0.013s. These are illustrative headless environment measurements, not device benchmarks. Disabling bare-top hides extra meshes without destroying shared geometry.
- The original animation, continuous body morphs, 194-bone decorative inner-layer overlay, authenticated server-controlled character data, age/sex/gender independence, and normal clothing recovery remain unchanged.

## Actual Blender source model work
- Added `tools/blender/anatomy_torso_skin_c13.py`, executed against the persistent editable `lifesim-anatomy-skeleton-v1/anatomy_skeleton_v1.blend`. This created a completely distinct collection `Anatomy_TorsoC13` containing a **closed 2162-vertex, 4320-triangle torso surface** with matching chest/waist and **actual geometric** inward umbilical cavity (sculptural indentation). Smooth vertex groups to original 194-bone anatomical rig `spine` and `chest`, original bone rig unchanged. Material has subtle independent procedural epidermal roughness.
- Persisted original `.blend`, a separate **`anatomy_torso_skin_c13.glb`** (198,788 bytes) containing the actual new torso and source armature, and **`anatomy_torso_skin_c13_review.png`** Cycles view. The initially overexposed white preview was recognized as an overpowered shared light rig and **rerendered** with a temporary controlled two-area-light setup, restoring the Blender scene afterward. Generator source updated to reproduce correct lighting without shipping extra lights into the model.
- Fresh-process Blender reopen checked **194 rig bones**, **17 Bullet rigid proxies/16 constraints**, **60 original muscle objects**, **6 adipose shells**, previous **26 C12 nail/areola/navel meshes**, **0 nonmanifold edge count** on new torso; separately imported exported GLB and verified one true skin object with 2162 vertices and 194-bone rig. Blender sculpt is independently editable; no direct binary replacement of production `character.glb` yet. In Godot the standalone new torso uses the same low-poly parametric design but is generated natively with all ten original body morphs.
