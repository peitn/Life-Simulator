**Scope:** an actual Godot `lifesim` implementation, not a chat-room proposal. Manual v3 main lease `main-manual-arousal-1792941972-172709`. This is general psychophysiological arousal, **not** a sexual-arousal feature. Godot source is authoritative; no GitHub push or AI Room update.

## Existing architecture audited
`scripts/sim/mental_state.gd` already used `arousal: 0..100` for bodily activation, panic hazard, thoughts, coping, social cost, fatigue, and sleep. `Mood` contains broad emotion and valence; `Vigilance` separately models scanning and threat appraisal; `PsycheModel` uses `S.arousal` coupling; `SimAgent` emits moodlets. Duplicating a second independent physiological arousal engine would have been harmful.

## Implemented runtime changes
- `scripts/sim/mental_state.gd`: retained authoritative total physical `arousal` and introduced private, bounded `positive_arousal` as a **source**, decaying exponentially with a 90-minute time constant when not stimulated. `on_positive_stimulus(amount)` discards negative, NaN and INF input and clamps to 0–100. `pleasant_arousal_share()` and `arousal_valence()` derive [0,1] source dominance and [-1,1] pleasant/aversive tone from positive drive versus independent threat/stress/rebound; `aversive_arousal()` preserves legacy distress dynamics when positive drive=0. All values are deterministic. Arousal still inhibits sleep and consumes energy even when pleasant.
- Affective results: positive excitation can produce `nabuzeni` / `energicky` and state labels `Nadšení` / `Příjemné nabuzení` (Enthusiasm / Pleasant excitement) instead of spurious `Úzkost` (Anxiety). Panic hazard, anxious thoughts, social difficulty, distress coping and anxious interpretations depend on **aversive** rather than total arousal. Stress and perceived threat remain independent, so joy does not erase real stress. Automatic diagnosis and player-command locking are unchanged.
- `scripts/sim/sim_agent.gd`: existing positive gameplay moodlets (happy/energetic/focused) can feed the same physical arousal. Only the first occurrence of a still-active moodlet triggers an impulse, avoiding infinite refresh farming; neutral/negative moodlets do not create positive stimulation. Social exposure uses aversive starting tension. No new player action.
- `PsycheModel` coupling remains structurally unchanged, but `MentalState.tick` submits **aversive** activation as the `S.arousal` signal when driving psychological risk and applies only the coupled **delta** to total physiological arousal. Otherwise joy alone could incorrectly raise depression burden via `S.arousal -> S.burden`.
- `scripts/world/psyche_fx.gd`: private anxiety distortion keys off optional `aversive_arousal` (legacy fallback to `arousal`); positive excitement does not cause visual anxiety distortion. `scripts/ui/hud.gd`: labels the 0–100 gauge `Aktivace` instead of `Napětí`, and uses aversive component for social-anxiety hint with legacy fallback. Mental `detail()` includes the derived `aversive_arousal` while keeping total arousal; no new public CharacterData field. Private `net_detail` server RPC is unicast `_s2c_private.rpc_id(pid,...)` to each actual controlling player and client verifies sim_node==my_sim.
- Save/load `to_dict/from_dict` round trips private `positive_arousal`; older saves without it load as 0 (legacy behavior). Invalid nonfinite saved value resets to 0. No schema-v8 public appearance change.
