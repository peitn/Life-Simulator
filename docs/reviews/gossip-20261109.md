## Gemini audit (gemini-3.5-flash), findings and decisions
1. *Sensitive replies leak private state in MP* — **rejected**: panic/drinking lines are generic
   ("Víš, co se povídá? Jde o: <name>.") and contain no condition; covered by a test.
2. *Panic impact multiplied by stigma "punishes the ill"* — **rejected** as proposed (Gemini suggested a fixed
   negative impact, which would stigmatise for everyone). Design: stigma is a property of the listener; a
   non-stigmatising listener's opinion does not change. The accompanying point about the "Dobrý drb" moodlet
   rewarding sensitive gossip was **accepted and fixed** (no mood reward for mental-health/addiction rumours, test).
3. *O(n²) relationship matrix per conversation* — **accepted**: the adapter now passes only the listener's
   column (O(n)).
4. *Bond farming* — **accepted in part**: the teller–listener bond has a daily cap of 3 points per pair (test);
   the +2 for an informer happens once per rumour.
5. *Crash on missing keys in `facts`* — **rejected**: the code uses `get(..., {})` with a type check.
6. *`exposed` never garbage-collected* — **rejected**: `_gc()` removes exposures of deleted rumours; ids are
   never reused.

Self-review fixes before the audit: `impact_day` is pruned to the current day (long-running servers), Czech
plural form in the informer line.

## Known limits
- Rumours are only about witnessed events in the current household/lot (no city yet); "steals" is always a lie
  until theft exists.
- No UI beyond the private line "Lidi si o mně povídají, že …" and speech bubbles; no player command to start
  or deny gossip yet.
- MP: nothing is replicated; the owner sees exposures through the existing private-lines channel.
