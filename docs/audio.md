# Audio

All music and sound is generated by the project's own **offline synthesizer** (`scripts/audio/synth.gd`).
It renders 16-bit WAV files. Loops wrap around the end of the buffer, including reverb, so they loop
seamlessly.

## Building the audio

WAV files are **not stored in git**. Generate them once after cloning:

```bash
godot --headless -s res://tools/build_audio.gd            # everything (music takes longest)
godot --headless -s res://tools/build_audio.gd -- rano    # a single id
```

Output goes to `audio/music/*.wav` and `audio/sfx/*.wav`. The `.import` files are set to
`importer="keep"`, because the game loads the WAVs at runtime with `wav_loader.gd`, and that also works
headless.

## Content

| Kind | Items |
|---|---|
| Music (`music_data.gd`) | 5 pieces: `rano` (morning), `den` (day), `vecer` (evening), `noc` (night), `melancholie` (low mood). Chord progressions come from the Audio Engine; melodies were composed by hand. |
| Ambience (`sound_recipes.gd`) | Dawn chorus, daytime birds, crickets at night, wind |
| Object loops | Shower, stove, TV, treadmill, played in 3D at the object while it is in use |
| UI | Click (speed change), chime (new friendship), conflict (argument) |

## AudioManager

- Buses: Music, Ambience, SFX and UI, with interior reverb, a compressor and muffled music when paused.
- **Music director:** picks a piece by time of day and switches to *melancholie* when the selected
  character is in a bad mood (with hysteresis). Transitions are smooth crossfades.
- Layered ambience that moves toward target weights smoothly.
- **Anxiety in sound:** the music is low-passed by anxiety level, and a heartbeat is generated at runtime. Its
  rate rises with anxiety, roughly 70→140 BPM. Both respect the distortion settings.
